## 🎮 Funcionalidades do Jogo

* **Banco de Perguntas Balanceado:** Sorteio dinâmico estruturado em 4 fáceis, 4 médias e 2 difíceis (total de 10 perguntas por partida).
* **Cronômetro:** 2 minutos (120 segundos) para pensar e responder a cada questão.
* **Ajudas Exclusivas:**
  * **-2:** Elimina duas alternativas incorretas.
  * **Sir Cuitos:** O mascote robótico que revela a resposta correta.
  * **Pular:** Até 3 chances para trocar de pergunta.
* **Caderno de Fórmulas:** Um painel dedicado contendo todas as fórmulas essenciais de PG, geometria e juros compostos para auxiliar nos cálculos.
* **Tutorial Completo:** Guia de instruções dividido em páginas na tela inicial.
